A V3 run nested under another native run may only narrow its parent's memory scopes, by the same rule as the legacy `memory` scope. Its versioned memory session's scope, the compiler's `scope` and the scope each built-in memory or transcript context source was pinned to must each lie within one of the parent run's scopes; a wider one fails the nested run with a `TypeError` ("widens its parent run's …") before anything is read or written. A V3 parent's scopes bound its children in turn, legacy `memory` children included.
