Evolutionary program search. `evolve` in the new edge-safe `@deuz-sdk/core/evolve` evolves the code between `EVOLVE-BLOCK-START` / `EVOLVE-BLOCK-END` markers with model-written SEARCH/REPLACE diffs, full rewrites and crossovers (0.6 / 0.3 / 0.1). It scores candidates through an evaluation cascade with thresholds, timeouts and an artifact side channel fed back into prompts. Parents are selected with seeded weighted, power-law, beam or Boltzmann sampling over islands, which migrate in a ring and reset the weakest island to the global best, and a MAP-Elites archive keeps the elites. A UCB1 bandit picks from a model ensemble. Novelty rejection works on embedding cosine similarity with an optional judge. A budget is mandatory, and every mutation is charged to a compacted child scope. Stops: target score, plateau, budget, `drain()` and `cancel()`. Candidates get deterministic IDs and idempotent writes, and generations commit with a compare-and-set, so `resumeEvolve` replays stored slots with zero model calls. `parseEvolveBlocks`, `applySearchReplace` and `buildMutationPrompt` are exported as pure helpers. `PopulationStore` has a memory backend and a SQLite backend in `@deuz-sdk/core/evolve/sqlite`. A `lease` option takes the run's lease from a shared `LeaseProvider` while a process drives it: a second executor fails with `EvolveLeaseError`, and one that loses its lease stops before its next write. A full rewrite or crossover takes its parent's final newline, so a program that ends without one no longer loses every rewrite to `frozen_changed`. Policy refusals, authentication errors and unknown models fail the run instead of rejecting every candidate, `modelCalls` counts only calls that sent a request, and a seed or resumed run that already meets `stopWhen` finishes without a model call.
