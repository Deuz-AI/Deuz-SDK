## Next: 2.5

These are the roadmap's targets for 2.5, not commitments. Each of them was out
of scope for 2.4:

- a CLI and TUI on top of the headless preview;
- a local daemon and a control server;
- realtime voice over WebRTC;
- lazy tool search (tools discovered when a run needs them);
- a local plugin lifecycle;
- dynamic agent tasks with a durable mailbox;
- a worktree integrator;
- an optional LSP or ACP preview.
